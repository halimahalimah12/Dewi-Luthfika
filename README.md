# LKP Dewi Luthfi’ka — Prototype Website

Prototype frontend berdasarkan spesifikasi yang diberikan.

## Jalankan
Buka `index.html` di browser.

## Catatan produksi
- Ganti placeholder foto dengan foto kegiatan LKP.
- Integrasikan backend/database untuk penyimpanan pendaftaran.
- Integrasikan payment flow/lynk.id sesuai URL/metode resmi yang digunakan.
- Implementasikan upload file ke storage yang aman.
- Buat generator PDF server-side atau client-side.
- Tambahkan status pendaftaran, konfirmasi pembayaran, dan autentikasi admin bila diperlukan.
- Verifikasi ulang daftar program/harga sebelum go-live; sumber spesifikasi memuat beberapa nama program yang tidak konsisten.
